Summary The crash message now shows the reason behind any Swift runtime failure, which makes debugging much easier. What's new? Crashes caused by a Swift runtime failure now show the reason as the crash message, such as Swift runtime failure: Unexpectedly found nil while unwrapping an Optional value.This works for any Swift runtime failure.
